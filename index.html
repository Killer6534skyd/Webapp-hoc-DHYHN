🤖 Bộ 4 Mẫu Prompt Chuẩn (Copy 1 Chạm)

Nhấn "Sao chép" ở mẫu phù hợp rồi gửi kèm tài liệu môn học của bạn cho AI.

PROMPT 1 — TẠO MÔN HỌC MỚI 
Đây là file HTML khung hệ thống ôn tập (`khung_he_thong_on_tap_da_mon_hoc_template.html`) và các tài liệu câu hỏi của môn [TÊN MÔN HỌC, VD: NỘI KHOA / NGOẠI KHOA / DƯỢC LÝ].
Nhiệm vụ của bạn:
1. Đọc toàn bộ các câu hỏi trong tài liệu đính kèm, lọc bỏ các câu trùng lặp hoàn toàn.
2. Chuẩn hóa học thuật y khoa cao nhất (theo Giáo trình Đại học Y Hà Nội & Hướng dẫn Bộ Y tế): hoàn thiện câu hỏi/đáp án bị khuyết, đính chính các câu khoanh/tô vàng sai trong đề gốc (đặt `is_trap: true` và ghi rõ vào `trap_note`), viết gợi ý lâm sàng (`hint`) và giải thích chuyên môn sâu (`exp`) kèm link tham chiếu (`ref_label`, `ref_url`).
3. Các câu hỏi tình huống thuộc cùng 1 bệnh án (Case lâm sàng) phải gắn mã `stem_id` và khai báo đầy đủ vào `BUILTIN_STEM_CLUSTERS`.
4. Chèn toàn bộ danh sách câu hỏi vào mảng `const QUESTIONS_BANK = [...]` và cập nhật tên môn học trong `DEFAULT_SUBJECT_CONFIG` (cùng `STORAGE_KEY` riêng cho môn này), giữ nguyên 100% tính năng, giao diện, hệ thống đăng nhập đồng bộ Google/Microsoft, chấm điểm phạt thân chung, bôi màu tách biệt comment, chèn media và lịch sử chỉnh sửa 7 ngày.
PROMPT 2 — BỔ SUNG ĐỀ REVIEW MỚI 
Đây là các file đề review mới để bạn bổ sung vào file HTML hiện tại của tôi. Nhiệm vụ của bạn:
1. Đối chiếu toàn bộ câu hỏi trong các file mới với mảng `QUESTIONS_BANK` hiện có trong HTML: câu nào trùng lặp hoàn toàn thì bỏ qua, câu nào mới hoặc có biến thể/bẫy đơn vị mới thì thêm tiếp nối số thứ tự `id: "q_..."` và `num` vào cuối `QUESTIONS_BANK`.
2. Chuẩn hóa đáp án và giải thích chuyên môn y khoa chính xác tuyệt đối, đính chính các câu tô vàng sai (`is_trap: true`, `trap_note`), gắn kết các chùm câu hỏi thân chung mới vào `BUILTIN_STEM_CLUSTERS`.
3. Giữ nguyên 100% các câu hỏi cũ và tất cả các tính năng đã tạo trong file HTML. Cập nhật lại các nhãn tổng số lượng câu hỏi trên giao diện khớp với tổng số câu mới.
PROMPT 3 — XUẤT MẢNG JSON 
Hãy đọc tài liệu đính kèm, chuẩn hóa học thuật từng câu hỏi và xuất ra một mảng JSON hợp lệ để tôi nhập vào phần mềm Ôn tập Y khoa theo đúng cấu trúc mỗi phần tử như sau:

PROMPT 4 — MỞ RỘNG TÍNH NĂNG 
Trên nền file HTML hệ thống ôn tập đính kèm, hãy bổ sung thêm cho tôi các tính năng sau:
- [Mô tả tính năng 1 bạn muốn thêm...]
- [Mô tả tính năng 2 bạn muốn thêm...]
Yêu cầu kỹ thuật bắt buộc:
1. Chỉnh sửa trực tiếp trên file HTML hiện tại, giữ nguyên toàn bộ dữ liệu trong `QUESTIONS_BANK`, `BUILTIN_STEM_CLUSTERS` và toàn bộ các tính năng đã có (Ôn tập, Thi thử, Flashcard 3D, Đồng bộ Google/Microsoft, Điểm phạt thân chung, Bôi màu tách biệt Comment, Media, Tìm kiếm #ID, Lịch sử chỉnh sửa 7 ngày, Nhớ vị trí cuộn).
2. Mọi dữ liệu mới phát sinh phải được lưu bền vững vào đối tượng `userProgress` và đồng bộ tương thích với `profilesRegistry` cũng như Cloud Sync.

Google Apps Script Web App URL / Firebase REST

Hướng dẫn 3 bước:
  1. Mở script.google.com → New project.
  2. Dán code dưới đây → Deploy → New deployment → Web app (Execute as: Me, Access: Anyone).
  3. Copy link /exec dán vào ô trên là xong!
function doPost(e) {
  var fileName = 'HMU_Medical_Study_Sync.json';
  var files = DriveApp.getFilesByName(fileName);
  if (files.hasNext()) { files.next().setContent(e.postData.contents); }
  else { DriveApp.createFile(fileName, e.postData.contents, MimeType.PLAIN_TEXT); }
  return ContentService.createTextOutput(JSON.stringify({status: 'ok', time: new Date().toISOString()})).setMimeType(ContentService.MimeType.JSON);
}
function doGet(e) {
  var files = DriveApp.getFilesByName('HMU_Medical_Study_Sync.json');
  var content = files.hasNext() ? files.next().getBlob().getDataAsString() : '{}';
  return ContentService.createTextOutput(content).setMimeType(ContentService.MimeType.JSON);
}
