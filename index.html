📖 TÀI LIỆU HƯỚNG DẪN SỬ DỤNG, PROMPT AI & KIẾN TRÚC CODE

Hướng dẫn Tái sử dụng Khung Hệ thống cho Bất kỳ Môn học Nào

Bạn có thể dùng file HTML khung này cho Nội khoa, Ngoại khoa, Sản, Nhi, Dược lý, Giải phẫu, Sinh lý hoặc bất kỳ môn học nào khác chỉ với 1 lần gửi Prompt cho AI hoặc nhập JSON trực tiếp.

1

Cách 1: Nhờ AI Gắn Câu Hỏi Trực Tiếp Vào File HTML

Đính kèm file HTML khung này cùng các file PDF / Word / Ảnh đề cương môn mới vào cuộc trò chuyện với AI, sau đó dán Prompt Mẫu Số 1 bên dưới. AI sẽ tự động biên soạn và trả về file HTML hoàn chỉnh của môn đó.

2

Cách 2: Nhờ AI Xuất Mảng JSON & Tự Nạp Vào Web

Nếu không muốn sửa code HTML, bạn dùng Prompt Mẫu Số 3 để nhờ AI chuyển đề thi PDF/Word thành mảng JSON, rồi mở tab Quản lý Câu hỏi → 📥 Nhập hàng loạt (JSON) dán vào là có ngay bộ đề.

3

Cách 3: Tự Tạo & Quản Lý Trên Giao Diện Web

Nhấn nút ⚙️ Đổi Môn Học để đặt tên môn mới, sau đó vào tab Quản lý Câu hỏi để thêm từng câu hỏi, chèn ảnh X-quang/ECG, âm thanh, video YouTube, gắn Case thân chung và đồng bộ lên Google Drive.

🤖 Bộ 4 Mẫu Prompt Chuẩn Để Gửi Cho AI Ở Các Lần Sau (Copy 1 Chạm)

Nhấn nút "📋 Sao chép Prompt" ở mẫu phù hợp rồi gửi kèm tài liệu môn học của bạn cho AI.

PROMPT MẪU 1 (DÙNG KHI TẠO WEB MÔN HỌC MỚI)

Dùng khi bạn đính kèm file HTML khung này + các file PDF/Word đề cương của một môn học mới:

Đây là file HTML khung hệ thống ôn tập (`khung_he_thong_on_tap_da_mon_hoc_template.html`) và các tài liệu câu hỏi của môn [TÊN MÔN HỌC, VD: NỘI KHOA / NGOẠI KHOA / DƯỢC LÝ].
Nhiệm vụ của bạn:
1. Đọc toàn bộ các câu hỏi trong tài liệu đính kèm, lọc bỏ các câu trùng lặp hoàn toàn.
2. Chuẩn hóa học thuật y khoa cao nhất (theo Giáo trình Đại học Y Hà Nội & Hướng dẫn Bộ Y tế): hoàn thiện câu hỏi/đáp án bị khuyết, đính chính các câu khoanh/tô vàng sai trong đề gốc (đặt `is_trap: true` và ghi rõ vào `trap_note`), viết gợi ý lâm sàng (`hint`) và giải thích chuyên môn sâu (`exp`) kèm link tham chiếu (`ref_label`, `ref_url`).
3. Các câu hỏi tình huống thuộc cùng 1 bệnh án (Case lâm sàng) phải gắn mã `stem_id` và khai báo đầy đủ vào `BUILTIN_STEM_CLUSTERS`.
4. Chèn toàn bộ danh sách câu hỏi vào mảng `const QUESTIONS_BANK = [...]` và cập nhật tên môn học trong `DEFAULT_SUBJECT_CONFIG` (cùng `STORAGE_KEY` riêng cho môn này), giữ nguyên 100% tính năng, giao diện, hệ thống đăng nhập đồng bộ Google/Microsoft, chấm điểm phạt thân chung, bôi màu tách biệt comment, chèn media và lịch sử chỉnh sửa 7 ngày.
PROMPT MẪU 2 (DÙNG KHI BỔ SUNG THÊM ĐỀ REVIEW MỚI)

Dùng khi bạn đã có file HTML của môn học và muốn nhờ AI nạp thêm các file đề review đợt mới vào:

Đây là các file đề review mới để bạn bổ sung vào file HTML hiện tại của tôi. Nhiệm vụ của bạn:
1. Đối chiếu toàn bộ câu hỏi trong các file mới với mảng `QUESTIONS_BANK` hiện có trong HTML: câu nào trùng lặp hoàn toàn thì bỏ qua, câu nào mới hoặc có biến thể/bẫy đơn vị mới thì thêm tiếp nối số thứ tự `id: "q_..."` và `num` vào cuối `QUESTIONS_BANK`.
2. Chuẩn hóa đáp án và giải thích chuyên môn y khoa chính xác tuyệt đối, đính chính các câu tô vàng sai (`is_trap: true`, `trap_note`), gắn kết các chùm câu hỏi thân chung mới vào `BUILTIN_STEM_CLUSTERS`.
3. Giữ nguyên 100% các câu hỏi cũ và tất cả các tính năng đã tạo trong file HTML. Cập nhật lại các nhãn tổng số lượng câu hỏi trên giao diện khớp với tổng số câu mới.
PROMPT MẪU 3 (NHỜ AI XUẤT FILE JSON ĐỂ TỰ NHẬP LÊN WEB)

Dùng khi bạn chỉ muốn AI xuất ra mảng JSON để tự bấm nút "📥 Nhập hàng loạt (JSON)" trên web:

Hãy đọc tài liệu đính kèm, chuẩn hóa học thuật từng câu hỏi và xuất ra một mảng JSON hợp lệ để tôi nhập vào phần mềm Ôn tập Y khoa theo đúng cấu trúc mỗi phần tử như sau:
[
  {
    "part": "Phần I",
    "topic": "Tên chủ đề bệnh học",
    "q": "Câu 1. Nội dung câu hỏi...",
    "options": ["A. ...", "B. ...", "C. ...", "D. ..."],
    "correct_idx": 0,
    "ans": "A. Nội dung đáp án đúng",
    "hint": "Gợi ý: ...",
    "exp": "Giải thích cơ chế bệnh sinh và phác đồ chi tiết...",
    "ref_label": "Tên phác đồ Bộ Y tế / Giáo trình",
    "ref_url": "https://thuvienphapluat.vn/...",
    "is_trap": false,
    "trap_note": ""
  }
]
PROMPT MẪU 4 (NHỜ AI CODE THÊM TÍNH NĂNG MỚI VÀO KHUNG)

Dùng khi bạn muốn nhờ AI nâng cấp thêm tính năng mới vào file HTML mà không làm hỏng hệ thống cũ:

Trên nền file HTML hệ thống ôn tập đính kèm, hãy bổ sung thêm cho tôi các tính năng sau:
- [Mô tả tính năng 1 bạn muốn thêm...]
- [Mô tả tính năng 2 bạn muốn thêm...]
Yêu cầu kỹ thuật bắt buộc:
1. Chỉnh sửa trực tiếp trên file HTML hiện tại, giữ nguyên toàn bộ dữ liệu trong `QUESTIONS_BANK`, `BUILTIN_STEM_CLUSTERS` và toàn bộ các tính năng đã có (Ôn tập, Thi thử, Flashcard 3D, Đồng bộ Google/Microsoft, Điểm phạt thân chung, Bôi màu tách biệt Comment, Media, Tìm kiếm #ID, Lịch sử chỉnh sửa 7 ngày, Nhớ vị trí cuộn).
2. Mọi dữ liệu mới phát sinh phải được lưu bền vững vào đối tượng `userProgress` và đồng bộ tương thích với `profilesRegistry` cũng như Cloud Sync.

💻 Cấu trúc Code & Schema Dữ liệu Chi tiết (Dành cho bạn & AI khi chỉnh sửa Code)

Khi bạn mở file HTML bằng trình soạn thảo code (VS Code, Notepad++) hoặc gửi cho AI, toàn bộ dữ liệu môn học nằm ở đầu thẻ <script> theo đúng chuẩn dưới đây:

1. Cấu trúc mỗi câu hỏi trong const QUESTIONS_BANK = [...]:
{
  "id": "q_1",                // Mã định danh duy nhất (q_1, q_2, ...)
  "num": 1,                   // Số thứ tự câu hỏi (dùng để tìm kiếm #1, #1-10)
  "part": "Phần I",           // Mã phần (Phần I, Phần II, Phần III, Phần IV, Phần V, Phần VI)
  "part_title": "PHẦN I: ...",// Tiêu đề đầy đủ của phần
  "topic": "Tim mạch",        // Chủ đề học phần (tự động nạp vào mọi bộ lọc Dropdown)
  "q": "Câu 1. Nội dung...",  // Nội dung câu hỏi
  "options": [                // Mảng từ 2 đến 5 phương án lựa chọn
    "A. Phương án A",
    "B. Phương án B",
    "C. Phương án C",
    "D. Phương án D"
  ],
  "correct_idx": 0,           // Chỉ số đáp án đúng (0 = A, 1 = B, 2 = C, 3 = D)
  "ans": "A. Phương án A",    // Chuỗi hiển thị tóm tắt đáp án đúng
  "hint": "Gợi ý: ...",       // Gợi ý lâm sàng / lý thuyết
  "exp": "Giải thích...",     // Giải thích chi tiết cơ chế và phác đồ
  "ref_label": "Bộ Y tế",     // Tên tài liệu tham khảo
  "ref_url": "https://...",   // Đường dẫn URL tham khảo
  "is_trap": false,           // true nếu là câu bẫy / đính chính đáp án sai ở đề gốc
  "trap_note": "",            // Nội dung cảnh báo bẫy
  "stem_id": "case_1",        // (Tùy chọn) Mã chùm câu hỏi thân chung nếu thuộc Case
  "media": []                 // (Tùy chọn) Mảng ảnh/audio/video đính kèm
}
2. Cấu trúc Chùm Câu hỏi Thân chung const BUILTIN_STEM_CLUSTERS = {...}:
const BUILTIN_STEM_CLUSTERS = {
  "case_1": {
    "id": "case_1",
    "title": "Case Lâm sàng 1: Bệnh nhân nam 60 tuổi khó thở cấp",
    "vignette": "Bệnh nhân nam 60 tuổi, tiền sử THA 10 năm, vào viện vì khó thở dữ dội, HA 180/100 mmHg, phổi ran ẩm dâng nhanh hai đáy...",
    "qIds": ["q_10", "q_11", "q_12"] // Danh sách ID các câu hỏi cùng chung Case này
  }
};

  subjectName: "Hệ Thống Ôn Tập & Thi Thử Đa Môn Học",

};

Vì ứng dụng chạy dưới dạng file .html độc lập không phụ thuộc máy chủ bên thứ ba, bạn có thể kết nối trực tiếp vào chính Google Drive cá nhân của bạn qua 1 trong 2 cách dưới đây để tự động đẩy (Push) và tải (Pull) dữ liệu qua Internet:

CÁCH 1 (KHUYÊN DÙNG - BỀN VỮNG NHẤT)

Liên kết qua Google Drive Web App URL (Google Apps Script / Firebase REST)

Hướng dẫn 3 bước tạo kho lưu trữ tự động trên Google Drive của bạn:
  1. Truy cập https://script.google.com (đăng nhập Google của bạn) → Nhấn New project (Dự án mới).
  2. Xóa mã mặc định, dán đoạn code bên dưới vào và nhấn Deploy (Triển khai) → New deployment → Web app. Chọn Execute as: Me và Who has access: Anyone.
  3. Copy đường dẫn Web app URL (`https://script.google.com/macros/s/.../exec`) dán vào ô bên trên là xong! Mọi thiết bị dùng chung link này sẽ tự động đồng bộ trực tiếp qua file HMU_Medical_Study_Sync.json trên Google Drive của bạn.
function doPost(e) {
  var fileName = 'HMU_Medical_Study_Sync.json';
  var files = DriveApp.getFilesByName(fileName);
  if (files.hasNext()) { files.next().setContent(e.postData.contents); }
  else { DriveApp.createFile(fileName, e.postData.contents, MimeType.PLAIN_TEXT); }
  return ContentService.createTextOutput(JSON.stringify({status: 'ok', time: new Date().toISOString()})).setMimeType(ContentService.MimeType.JSON);
}
function doGet(e) {
  var files = DriveApp.getFilesByName('HMU_Medical_Study_Sync.json');
  var content = files.hasNext() ? files.next().getBlob().getDataAsString() : '{}';
  return ContentService.createTextOutput(content).setMimeType(ContentService.MimeType.JSON);
}
